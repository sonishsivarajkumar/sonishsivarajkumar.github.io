# Images Directory

Place your images here:

- `profile.jpg` or `profile.png` - Your professional headshot (300x300px recommended)
- `favicon.ico` - Website favicon
- `research-1.jpg`, `research-2.jpg`, etc. - Research project images
- `background.jpg` - Optional background image for hero section

## Image Guidelines

- Profile photo: Professional headshot, square aspect ratio, 300x300px minimum
- Favicon: 32x32px or 16x16px ICO format
- Research images: 800x600px recommended, landscape orientation
- All images should be optimized for web (compressed but high quality)

## Adding Images

1. Upload your images to this folder
2. Update the corresponding HTML in `index.html`
3. For the profile photo, replace the `.image-placeholder` div with:
   ```html
   <img src="images/profile.jpg" alt="Sonish Sivarajkumar" class="profile-image">
   ```
4. Add the corresponding CSS styling in `styles.css`
